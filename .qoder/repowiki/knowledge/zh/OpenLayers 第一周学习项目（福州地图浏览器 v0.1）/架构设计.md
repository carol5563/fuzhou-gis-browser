单页应用结构：`index.html` 作为入口，通过 `<script type="module" src="/src/main.js">` 引入 ES Module 主逻辑；`package.json` 声明依赖 `ol@^10.9.0` 和开发依赖 `vite@^8.1.1`，提供 `dev/build/preview` 三个脚本。项目采用原生 JS + Vite 零框架方案，核心概念围绕 OpenLayers 的 Map / View / Layer / Source 四要素组织代码，底图通过 XYZ 源接入高德瓦片服务（webrd/webst），坐标系转换使用 `fromLonLat` / `toLonLat` 在 EPSG:4326 与 EPSG:3857 之间切换。README.md 记录本周知识点、运行方式和踩坑总结，`GIS学习计划-刘珊.md` 是配套的 6 个月全栈 WebGIS 学习计划文档。
