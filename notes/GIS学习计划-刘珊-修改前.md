先自己写（哪怕写不出、写得烂），卡住了再看示例——而不是先看示例再抄；
抄进去的每一行都要能说出它为什么在这（比如"为什么 center 要 fromLonLat 包一层"，答不上就别往下走）；
每次那节课结束，关掉所有参考，凭记忆把核心功能重写一遍。写得出来才算过，写不出说明没内化。

我给的骨架/💡提示 = 告诉你"这一步要干什么、大概长什么样"（相当于题目和思路）；
官方文档/示例 = 查具体某个 API 怎么调、参数是什么（这个一辈子都要查，不算作弊，越熟练越好）；
你自己做的 = 把这些拼成完整逻辑 + 每行都懂 + 最后能脱稿重写。
